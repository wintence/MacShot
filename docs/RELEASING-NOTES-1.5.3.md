# MacShot 1.5.3

## What's new

- **A new icon.** The app and tray icons were redrawn, with every Windows
  size inside the `.ico`.
- **New themes.** The interface is now black and white: a near-black dark
  theme with white text and a white light theme with black text.

## Two files — pick one

| File | Size | Needs .NET | Use it when |
|---|---|---|---|
| `MacShot-lite.exe` | ~0.4 MB | .NET 8 Desktop Runtime installed | everyday machine with the runtime |
| `MacShot-full.exe` | ~68 MB | nothing | the machine may lack the runtime |

Both contain the same program; the name is the only difference.
